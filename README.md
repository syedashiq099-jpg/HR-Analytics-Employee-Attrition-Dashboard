# HR-Analytics-Employee-Attrition-Dashboard

## 📌 Project Overview

This project is an interactive **HR Analytics Dashboard** developed using **Microsoft Power BI** to analyze employee data and understand workforce and employee attrition trends.

The dashboard provides a consolidated view of employee count, attrition, attrition rate, average age, average salary, years of experience, education, gender, job roles, age groups, and salary slabs.

The dashboard is designed to help identify important HR patterns and provide meaningful insights into employee attrition and workforce characteristics.

## ✨ Key Features

### 👥 Employee Overview
- Displays the total number of employees
- Provides an overall view of the workforce

### 📉 Attrition Analysis
- Displays total employee attrition
- Calculates and presents the attrition rate
- Helps analyze overall employee turnover

### 🎓 Education-wise Attrition
- Analyzes employee attrition across different education fields
- Provides a comparison of attrition among education categories

### 🚻 Gender-wise Attrition
- Visualizes employee attrition by gender
- Shows the distribution of attrition between male and female employees

### 💼 Job Role Analysis
- Displays attrition count by job role
- Shows average age for different job roles
- Shows average years of experience for different job roles

### 🎂 Age Group Analysis
- Analyzes employee attrition across different age groups
- Helps identify which age categories have higher attrition

### 💰 Salary Slab Analysis
- Analyzes attrition across different salary ranges
- Provides a visual comparison of attrition based on salary slabs

### 📊 KPI Cards
The dashboard includes key HR metrics such as:

- Total Employee Count
- Total Attrition
- Attrition Rate
- Average Age
- Average Salary
- Average Years of Experience

### 🔎 Interactive Filtering
- Department-based filtering
- Enables users to interact with the dashboard and explore specific employee categories

## 📈 Dashboard Insights
